# Oldernew AI content guide

This repository contains the encrypted static publication files. The guide's HTML, scripts, images, and PDFs are encrypted before publication. Visitors open `index.html` and enter the shared password to decrypt them in their browser. Do not add plaintext guide files or the password to this repository.

The shared password and the editable plaintext source are maintained separately by the site owner. This client-side protection cannot rate-limit offline password guessing; use a stronger password and server-side authentication for more sensitive material.
